# Cerst.ONE

Het kerstspel van Sterc.ONE. Schiet Pixel weg en gooi alle hallucinaties om.

- `index.html` is het hele spel in één bestand.
- `voice.mp3` (optioneel) is de stem van Pixel bij de begroeting.

Het spel staat live via een Cloudflare Worker die deze bestanden van de `main`-branch ophaalt. Een wijziging hier staat na een paar minuten online.
